## 完全背包理论基础-二维DP数组

### 完全背包定义

有N件物品和一个最多能背重量W的背包，第i件物品的重量是weight[i]，得到的价值是value[i]。**每件物品有无限个（可以放进背包多次）**，求解怎么放价值总和最大

**完全背包和01背包唯一不同的地方就是，每种物品有无限件**

还是使用**动态规划**的方式来做，动归五部曲：

1. 确定dp数组以及下标含义：

dp[i][j]表示下标[0-i]的物品，每个物品取无限次，放进容量为j的背包，价值总和最大是多少

2. 确定递推公式

还是拿dp[1][4]来说:
有两种情况：放1和不放1。
如果不放1，那么就是dp[0][4]
如果放1，**背包就要先留出物品1的容量**，目前容量是4，1的容量是为3，此时背包剩下容量为1。容量为1，只考虑放物品0和1，**最大价值应该是dp[1][1] + v[1]**（这就不是dp[0][1]）而在完全背包中，物品是可以放无限个，所以 **即使空出物品1空间重量，那背包中也可能还有物品1，所以此时我们依然考虑放 物品0 和 物品1 的最大价值即： dp[1][1]**， 而不是 dp[0][1]
状态转移方程：dp[i][j] = max(dp[i - 1][j], dp[i][j - w[i]] + v[i])

3. dp数组如何初始化
   
初始化一定要与dp数组吻合，否则递推会很乱

dp[i][0]的话，不管选哪个，背包价值都是0，由递推式可以看出，有一个方向是从i-1推出来的，所以i为0的时候也要初始化
dp[0][j]:j < weight[0] 就是0，j >= weight[0] dp[0][j] = value[0] * (j // weight[0])

4. 确定遍历顺序
   先遍历谁都是可以的，只要保证顺序是从左上到右下的即可

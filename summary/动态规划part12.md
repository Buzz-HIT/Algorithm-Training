### 115.不同的子序列
题目如果不是子序列，而是要求连续的序列，可以考虑用KMP算法来解决，但本题是子序列，所以我们使用动态规划来解决。

这道题目相对于72. 编辑距离，简单了不少，因为本题相当于只有删除操作，不用考虑替换增加之类的。
但相对于刚讲过的动态规划：392.判断子序列 (opens new window)就有难度了，这道题目双指针法可就做不了了，来看看动规五部曲分析如下：

1. 确定dp数组以及下标的含义：
   dp[i][j]:以i-1结尾的s子序列出现以j-结尾的t的个数为dp[i][j]。
2. 确定递推公式：
    参照前面的经验，这一类问题，主要就分析两种情况：
    - s[i - 1]与t[j - 1]相同
    - s[i - 1]与t[j - 1]不相同
    相同时，dp[i][j]有两部分组成。一部分是用s[i - 1]来匹配，那么个数为dp[i - 1][j - 1]。即不需要考虑当前s子串和t子串的最后一位字母，所以只需要 dp[i-1][j-1]。**一部分是不用s[i - 1]来匹配，个数为dp[i - 1][j]。**这里比较难懂，举个例子来说，s：bagg 和 t：bag ，s[3] 和 t[2]是相同的，但是字符串s也可以不用s[3]来匹配，即用s[0]s[1]s[2]组成的bag。当然也可以用s[3]来匹配，即：s[0]s[1]s[3]组成的bag。
    **所以当s[i - 1] 与 t[j - 1]相等时，dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j];**
    当s[i - 1]与t[j - 1]不相同，那么s[i - 1]肯定不能用来匹配t[j - 1]，所以只能是不用s[i - 1]来匹配，那么个数为dp[i - 1][j]。
    **即：dp[i][j] = dp[i - 1][j];**
3. dp数组如何初始化：
   从递推公式dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j]; 和 dp[i][j] = dp[i - 1][j]; 中可以看出dp[i][j] 是从上方和左上方推导而来，那么 dp[i][0] 和dp[0][j]是一定要初始化的。
   初始化时要回顾dp数组的定义，dp[i][0]:表示以i-1为结尾的s可以随便删除元素，出现空字符串的个数。那么dp[i][0]一定都是1，因为也就是把以i-1为结尾的s，删除所有元素，出现空字符串的个数就是1。
   dp[0][j]:空字符串里面处不来任何非空字符串，所以dp[0][j]一定都是0。
   dp[0][0]:空字符串出现空字符串的个数为1。
4. 遍历顺序：
   由递推公式可以看出，是从左上方和正上方推出来的

### 583.两个字符串的删除操作

本题由两种思路，一种是使用动态规划，另一种是使用最长公共子序列来解决。

#### 方法一：动态规划

与上个题就类似了，我们来分析一下：
1. dp[i][j]:表示word1的前i个字母和word2的前j个字母相同所需要的最少删除操作数。
2. 递推公式:
    这回就是两个字符串都可以删除了，所以主要分析两种情况：
    - word1[i - 1]与word2[j - 1]相同:dp[i][j] = dp[i - 1][j - 1]
    - word1[i - 1]与word2[j - 1]不相同:就会有三种情况：
        1. 删除word1[i - 1]，那么就变成了word1的前i-1个字母和word2的前j个字母相同，所以操作数为dp[i - 1][j] + 1
        2. 删除word2[j - 1]，那么就变成了word1的前i个字母和word2的前j-1个字母相同，所以操作数为dp[i][j - 1] + 1
        3. 同时删除word1[i - 1]和word2[j - 1]，那么就变成了word1的前i-1个字母和word2的前j-1个字母相同，所以操作数为dp[i - 1][j - 1] + 2
    三者取最小值即可
3. 初始化：
   通过递推公式，我们可以看出，推导方向是上方和左上方和左方推导而来，所以dp[i][0]和dp[0][j]一定要初始化。
    dp[i][0]:表示word1的前i个字母和空字符串相同所需要的最少删除操作数，那么肯定是i，因为要把word1的i个字母都删除掉。
    dp[0][j]:表示空字符串和word2的前j个字母相同所需要的最少删除操作数，那么肯定是j，因为要把word2的j个字母都删除掉。
4. 遍历顺序：
   由递推公式可以看出，是从左上方和正上方和左方推出来的。

#### 方法二：公共最长子序列

找到两个字符串的最长公共子序列，然后求出其长度，超过这个长度的值，就是要删除的个数（两个字符串删除的个数加和）

1. dp[i][j]:表示word1前i个字母和word2前j个字母的最长公共子序列
2. 递推公式：
   - word1[i - 1]与word2[j - 1]相同:dp[i][j] = dp[i - 1][j - 1] + 1
   - word1[i - 1]与word2[j - 1]不相同:dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
3. 初始化：
    dp[i][0]和dp[0][j]都初始化为0,因为空字符串和任何字符串的最长公共子序列都是0
4. 遍历顺序：
   由递推公式可以看出，是从左上方和正上方和左方推出来的。


### 72.编辑距离
编辑距离问题是动态规划中的经典问题，主要分析三种操作：插入、删除、替换。看起来是非常复杂，因为有三种操作，但是我们使用动态规划进行一步步分析，就会比较简单，注意，要时刻牢记dp数组的定义

1. dp[i][j]:表示word1的前i个字母转换成word2的前j个字母，最近的编辑距离为dp[i][j]
2. 递推公式：
   - 如果word1[i - 1] == word2[j - 1]:dp[i][j] = dp[i - 1][j - 1]
   - 否则，就要进行增，删，改：
      - 操作一：word1删除一个元素，那么就是以下标i - 2为结尾的word1 与 j-1为结尾的word2的最近编辑距离 再加上一个操作。即 dp[i][j] = dp[i - 1][j] + 1;
      - 操作二：word2删除一个元素，那么就是以下标i - 1为结尾的word1 与 j-2为结尾的word2的最近编辑距离 再加上一个操作。即 dp[i][j] = dp[i][j - 1] + 1;
      **添加元素呢？其实一个字符串删除元素，相对的就等价于另一个字符串增加元素，所以两种删除的情况就等于两种增加的情况。**
      - 操作三：替换元素，将word1[i - 1]替换与word2[j - 1]相同，那么就和上面相同的情况一样了，再加上一个替换的操作。即dp[i][j] = dp[i - 1][j - 1] + 1
以上三者取最小值

3. 初始化：
   通过上面的递推公式可以看出，当前的值是通过左，左上，上推出来的，所以，要初始化dp[i][0]和dp[0][j]
   根据dp的定义，dp[i][0] = i(删除i个元素)，dp[0][j]=[j](同理)
4. 遍历顺序：左上到右下
5. 模拟：草稿纸

### 判断子序列

[392.判断子序列](https://leetcode.cn/problems/is-subsequence/)，给定字符串 s 和 t ，判断 s 是否为 t 的子序列。

这道题目 其实是可以用双指针或者贪心的的，但是我在开篇的时候就说了这是编辑距离的入门题目，因为从题意中我们也可以发现，只需要计算删除的情况，不用考虑增加和替换的情况。

给定字符串 s 和 t ，判断 s 是否为 t 的子序列。

这道题目 其实是可以用双指针或者贪心的的，但是我在开篇的时候就说了这是编辑距离的入门题目，因为从题意中我们也可以发现，只需要计算删除的情况，不用考虑增加和替换的情况。

状态转移方程：
```python
if s[i - 1] == t[j - 1]:
    dp[i][j] = dp[i - 1][j - 1]
else:
    dp[i][j] = dp[i][j - 1] # 只删除t，因为要保证s是t的子序列
```
如果子序列长度和s相等，那么说明s是t的子序列。

### 不同的子序列

[115.不同的子序列](https://leetcode.cn/problems/distinct-subsequences/)，给定一个字符串 s 和一个字符串 t ，计算在 s 的不同子序列中 t 出现的个数。
本题虽然只有删除操作，但是双指针就做不了了，我们需要使用动态规划来解决。

当s[i - 1] 与 t[j - 1]相等时，dp[i][j]可以有两部分组成。

一部分是用s[i - 1]来匹配，那么个数为dp[i - 1][j - 1]。

一部分是不用s[i - 1]来匹配，个数为dp[i - 1][j]。

这里可能有同学不明白了，为什么还要考虑 不用s[i - 1]来匹配，都相同了指定要匹配啊。

例如： s：bagg 和 t：bag ，s[3] 和 t[2]是相同的，但是字符串s也可以不用s[3]来匹配，即用s[0]s[1]s[2]组成的bag。

当然也可以用s[3]来匹配，即：s[0]s[1]s[3]组成的bag。

所以当s[i - 1] 与 t[j - 1]相等时，dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j];

当s[i - 1] 与 t[j - 1]不相等时，dp[i][j]只有一部分组成，不用s[i - 1]来匹配，即：dp[i - 1][j]

所以递推公式为：dp[i][j] = dp[i - 1][j];

```python
if s[i - 1] == t[j - 1]:
    dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j]
else:
    dp[i][j] = dp[i - 1][j]
```

### 两个字符串的删除操作

[583.两个字符串的删除操作](https://leetcode.cn/problems/delete-operation-for-two-strings/)，给定两个单词 word1 和 word2，找到使得两个单词相同所需的最小步数，每步可以删除任意一个字符串中的一个字符。

如果word1[i - 1]与word2[j - 1]相同:dp[i][j] = dp[i - 1][j - 1]
如果word1[i - 1]与word2[j - 1]不相同:就会有三种情况：
1. 删除word1[i - 1]，那么就变成了word1的前i-1个字母和word2的前j个字母相同，所以操作数为dp[i - 1][j] + 1
2. 删除word2[j - 1]，那么就变成了word1的前i个字母和word2的前j-1个字母相同，所以操作数为dp[i][j - 1] + 1
3. 同时删除word1[i - 1]和word2[j - 1]，那么就变成了word1的前i-1个字母和word2的前j-1个字母相同，所以操作数为dp[i - 1][j - 1] + 2
三者取最小值即可

```python
if word1[i - 1] == word2[j - 1]:
    dp[i][j] = dp[i - 1][j - 1]
else:
    dp[i][j] = min(dp[i - 1][j] + 1, dp[i][j - 1] + 1, dp[i - 1][j - 1] + 2)
``` 

### 编辑距离

[72.编辑距离](https://leetcode.cn/problems/edit-distance/)，给你两个单词 word1 和 word2，计算出将 word1 转换成 word2 所使用的最少操作数。（增删改）

其实我觉得本题最需要想到的在于，删和增是对称的操作，否则，增和删都考虑的话就会很麻烦,删除这个等于增加另一个

状态转移方程：
```python
if word1[i - 1] == word2[j - 1]:
    dp[i][j] = dp[i - 1][j - 1]
else:
    dp[i][j] = min(dp[i - 1][j], dp[i][j - 1], dp[i - 1][j - 1]) + 1
```

**在整个动规的过程中，最为关键就是正确理解dp[i][j]的定义！**
